# คู่มือผู้ใช้ TAVIS

TAVIS (Traffic Awareness Vaccine Intelligent System) เป็นระบบวัคซีนจราจร ของสำนักงานเขตพื้นที่การศึกษามัธยมศึกษามหาสารคาม

## เว็บไซต์สาธารณะ

- หน้าแรก / เกี่ยวกับเรา / ข่าว / FAQ / ติดต่อ
- **แผนการเรียนรู้** — ดูหลักสูตร 14 ชั่วโมง
- กิจกรรมชมรม / แกลเลอรี่

## สมาชิกชมรมและครูที่ปรึกษา

หลังเข้าสู่ระบบ (`/login`):

1. **แผนการเรียนรู้** — ดูแผนแต่ละชั่วโมง ใบความรู้ ใบงาน สื่อ
2. **สมาชิกชมรม** — ครูบันทึกข้อมูลนักเรียนและสถานะการเรียน
3. **กิจกรรมชมรม** — บันทึกกิจกรรม อบรม การเข้าเรียน แบบทดสอบ ใบขับขี่ กิจกรรมช่วยเหลือสังคม
4. **รายงาน** — ส่งออก PDF / Excel ตามสิทธิ์

## หลักสูตร 14 ชั่วโมง (สรุป)

| ชม. | หัวข้อ |
|---|---|
| 1–2 | อุบัติเหตุ / จิตสำนึกและมารยาท |
| 3–4 | กฎหมายและเครื่องหมายจราจร |
| 5–10 | TSY Module 1–6 (คิดเอาชีวิตรอด / SHELL / DECIDE / ทัศนคติ / AMISAFE) |
| 11–12 | ฉุกเฉิน–ปฐมพยาบาล / สาธิตขับขี่ |
| 13–14 | ใบอนุญาตขับขี่ / ประเมินผล |
